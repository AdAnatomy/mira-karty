# Карусели Миры для TikTok

Здесь лежат только картинки каруселей и шаблон, по которому они рисуются. Паролей, токенов и кода бота здесь нет.

- `posts/ГГГГ-ММ-ДД/` — слайды одной карусели (1.jpg, 2.jpg, ...), ссылки на них получает Metricool.
- `journal.json` — журнал публикаций: дата, карта, рубрика, статус.
- `kit/` — шаблон: иллюстрации 22 старших арканов, стили, шрифты, рендер.

Рендер: `node kit/render.js spec.json posts/ГГГГ-ММ-ДД` (нужен Playwright с Chromium).
